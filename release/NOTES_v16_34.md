# Preview 34

Control Center changes:
- Compact header, contract controls, Registered VM rows, Planning tools, and Pair status toolbar.
- Planning Select All and Clear Selection sit beneath Show / hide columns. The Order column is removed; manual row ordering remains available.
- Group by Fund groups the firm field alphabetically, repeats the selected column headers, and preserves sorting, selection, resizing, and saved layouts.
- Build pairs has compact Remove All Pair and Add All to Q controls below the strategy box. Strategy details start collapsed.
- Pair status columns can be dragged into a saved order. Each account balance shows its configured dollar profit and loss limits, adjusted for the pair ratio.
- The beta strategy is named Test Non-consitency. Suggestions require stage names containing Evaluation or Challenge, case-insensitively. Existing consistency, realized P&L, InitialBalance, drawdown, different-firm, minimum-profit, and target-overshoot rules remain in place.
- Older beta suggestions must be regenerated before confirmation so the new eligibility rule is checked.

VM agent and trade execution logic are unchanged. Update the Control Center computer. Existing compatible agents can stay installed.
