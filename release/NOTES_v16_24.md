# Preview 24

- Pair cards in Planning and Pair Status show Realized P&L immediately after Current Balance on the first metrics line. Positive values are green; negative values are red.
- Drawdown, Stop, Largest Profit Day, and Trading Days use a smaller font.
- Pair Status data columns can be sorted by clicking their headers; click again to reverse the order. Default sorting is Completed Time, newest first, with missing times last. Numeric columns sort numerically.
- Sorting includes history and does not change queue execution order. Column resizing remains available.
- Preview 23 agents remain compatible.
